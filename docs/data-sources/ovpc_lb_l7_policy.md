# viettelidc_ovpc_lb_l7_policy (Data Source)

Look up a single L7 policy by ID or name on a listener.

## Example Usage

### Pure Name-Based Lookup (Zero Hardcoded IDs)

```terraform
data "viettelidc_ovpc_vpc" "main" {
  name = "my-vpc"
}

# Resolve listener dynamically from Load Balancer name and port
data "viettelidc_ovpc_lb_listener" "http" {
  vpc_id             = data.viettelidc_ovpc_vpc.main.id
  load_balancer_name = "web-lb"
  port               = 80
}

# Look up L7 policy by name on that listener
data "viettelidc_ovpc_lb_l7_policy" "dev_policy" {
  vpc_id      = data.viettelidc_ovpc_vpc.main.id
  listener_id = data.viettelidc_ovpc_lb_listener.http.id
  name        = "dev"
}

output "policy_action" {
  value = data.viettelidc_ovpc_lb_l7_policy.dev_policy.action
}
```
