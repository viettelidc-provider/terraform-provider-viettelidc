# viettelidc_ovpc_volume (Data Source)

Look up a single ViettelIDC block storage volume by id or name.

## Example Usage

```terraform
  id     = "228025"
  vpc_id = data.viettelidc_ovpc_vpc.main.id
}

# Look up by name (exact match)

  name   = "root-vm-2c9b96bd"
  vpc_id = data.viettelidc_ovpc_vpc.main.id
}
```
