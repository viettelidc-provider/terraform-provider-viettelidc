# viettelidc_ovpc_lb_pool (Data Source)

Look up a single Load Balancer backend pool by name or ID.

## Example Usage

### 1. Lookup by Load Balancer Name and Pool Name (Recommended / Zero IDs)

```terraform
data "viettelidc_ovpc_vpc" "main" {
  name = "my-vpc"
}

data "viettelidc_ovpc_lb_pool" "backend_pool" {
  vpc_id             = data.viettelidc_ovpc_vpc.main.id
  load_balancer_name = "web-lb"
  name               = "web-backend-pool"
}

output "pool_id" {
  value = data.viettelidc_ovpc_lb_pool.backend_pool.id
}
```

### 2. Lookup by Load Balancer ID (Numeric)

```terraform
data "viettelidc_ovpc_lb_pool" "by_id" {
  vpc_id           = data.viettelidc_ovpc_vpc.main.id
  load_balancer_id = data.viettelidc_ovpc_load_balancer.web.load_balancer_id
  name             = "web-backend-pool"
}
```

## Schema

### Required

- `vpc_id` (Number) VPC ID.

### Optional

- `id` (Number) Pool ID.
- `load_balancer_id` (Number) Load Balancer ID. At least one of `load_balancer_id` or `load_balancer_name` must be specified.
- `load_balancer_name` (String) Load Balancer name. If set, looks up the load balancer by name in the VPC to retrieve its ID automatically.
- `name` (String) Pool name.

### Read-Only

- `algorithm` (String) Load balancing algorithm (ROUND_ROBIN, LEAST_CONNECTIONS, SOURCE_IP).
- `protocol` (String) Pool protocol (HTTP, TCP, etc.).
- `status` (String) Pool status.
