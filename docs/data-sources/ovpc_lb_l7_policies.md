# viettelidc_ovpc_lb_l7_policies (Data Source)

Lists ViettelIDC vLB Layer 7 Policies attached to a specific Listener.

## Example Usage

### Pure Name-Based Policy Listing (Zero Hardcoded IDs)

```terraform
data "viettelidc_ovpc_vpc" "main" {
  name = "my-vpc"
}

# Resolve listener dynamically using LB name and port
data "viettelidc_ovpc_lb_listener" "http" {
  vpc_id             = data.viettelidc_ovpc_vpc.main.id
  load_balancer_name = "web-lb"
  port               = 80
}

# List all L7 policies attached to the resolved listener
data "viettelidc_ovpc_lb_l7_policies" "listener_policies" {
  vpc_id      = data.viettelidc_ovpc_vpc.main.id
  listener_id = data.viettelidc_ovpc_lb_listener.http.id
}

output "policy_names" {
  value = [for p in data.viettelidc_ovpc_lb_l7_policies.listener_policies.policies : p.name]
}
```

### Nested Schema for `policies`

Read-Only:

- `action` (String) Policy action: `REJECT`, `REDIRECT_TO_URL`, or `REDIRECT_TO_POOL`.
- `description` (String) Description of the L7 policy.
- `id` (String) Policy ID as string.
- `listener_id` (Number) Listener ID.
- `name` (String) Name of the L7 policy.
- `number_of_rules` (Number) Number of L7 rules attached to this policy.
- `policy_id` (Number) Internal CMP policy ID.
- `pool_name` (String) Redirect Pool Name if action is `REDIRECT_TO_POOL`.
- `priority` (Number) Evaluation priority on the listener.
- `redirect_pool_id` (Number) Target pool ID when action is `REDIRECT_TO_POOL`.
- `redirect_url` (String) Target redirect URL when action is `REDIRECT_TO_URL`.
- `status` (String) Lifecycle status of the policy.
