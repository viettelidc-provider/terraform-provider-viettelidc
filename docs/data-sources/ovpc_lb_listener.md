# viettelidc_ovpc_lb_listener (Data Source)

Look up a single Load Balancer listener by name, port, or ID.

## Example Usage

### 1. Lookup by Load Balancer Name and Port (Recommended / Zero IDs)

```terraform
data "viettelidc_ovpc_vpc" "main" {
  name = "my-vpc"
}

data "viettelidc_ovpc_lb_listener" "http" {
  vpc_id             = data.viettelidc_ovpc_vpc.main.id
  load_balancer_name = "web-lb"
  port               = 80
}

output "listener_id" {
  value = data.viettelidc_ovpc_lb_listener.http.id
}
```

### 2. Lookup by Load Balancer Name and Listener Name

```terraform
data "viettelidc_ovpc_lb_listener" "custom" {
  vpc_id             = data.viettelidc_ovpc_vpc.main.id
  load_balancer_name = "web-lb"
  name               = "web-lb-listener"
}
```

### 3. Lookup by Load Balancer ID (Numeric)

```terraform
data "viettelidc_ovpc_lb_listener" "by_id" {
  vpc_id           = data.viettelidc_ovpc_vpc.main.id
  load_balancer_id = data.viettelidc_ovpc_load_balancer.web.load_balancer_id
  port             = 443
}
```

## Schema

### Required

- `vpc_id` (Number) VPC ID.

### Optional

- `id` (Number) Listener ID.
- `load_balancer_id` (Number) Load Balancer ID. At least one of `load_balancer_id` or `load_balancer_name` must be specified.
- `load_balancer_name` (String) Load Balancer name. If set, looks up the load balancer by name in the VPC to retrieve its ID automatically.
- `name` (String) Listener name.
- `port` (Number) Listener protocol port.

### Read-Only

- `default_pool_id` (Number) Default backend pool ID associated with the listener.
- `protocol` (String) Listener protocol (HTTP, HTTPS, TCP, etc.).
- `status` (String) Listener status.
