# viettelidc_ovpc_lb_l7_policy (Resource)

Manages a ViettelIDC vLB Layer 7 Policy attached to an HTTP or TERMINATED_HTTPS Listener.

L7 Policies allow routing and request manipulation based on Layer 7 HTTP attributes (Host, Path, Header, Cookie, File Type). When attached to a listener, policies are evaluated in order of their `priority` (lower numbers evaluated first).

~> **Note:** Actions `REJECT`, `REDIRECT_TO_URL`, and `REDIRECT_TO_POOL` require replacement (`RequiresReplace`) when changed.

## Example Usage

### Complete Name-Based Configuration (Zero Hardcoded IDs)

```terraform
data "viettelidc_ovpc_vpc" "main" {
  name = "my-vpc"
}

# 1. Discover HTTP listener dynamically by Load Balancer name and port
data "viettelidc_ovpc_lb_listener" "http" {
  vpc_id             = data.viettelidc_ovpc_vpc.main.id
  load_balancer_name = "web-lb"
  port               = 80
}

# 2. Discover backend pool dynamically by Load Balancer name and pool name
data "viettelidc_ovpc_lb_pool" "api" {
  vpc_id             = data.viettelidc_ovpc_vpc.main.id
  load_balancer_name = "web-lb"
  name               = "api-backend-pool"
}

# Policy 1: Reject traffic matching bad bots / scrapers
resource "viettelidc_ovpc_lb_l7_policy" "block_bad_bots" {
  vpc_id      = data.viettelidc_ovpc_vpc.main.id
  listener_id = data.viettelidc_ovpc_lb_listener.http.id
  name        = "block-bad-bots"
  description = "Reject suspicious user agents"
  action      = "REJECT"
  priority    = 1
}

# Policy 2: Redirect legacy domain to new URL
resource "viettelidc_ovpc_lb_l7_policy" "redirect_to_new_domain" {
  vpc_id       = data.viettelidc_ovpc_vpc.main.id
  listener_id  = data.viettelidc_ovpc_lb_listener.http.id
  name         = "redirect-old-domain"
  description  = "Redirect legacy domain requests to new portal"
  action       = "REDIRECT_TO_URL"
  redirect_url = "https://newportal.example.com"
  priority     = 10
}

# Policy 3: Route API requests to dedicated backend pool (referenced by pool name)
resource "viettelidc_ovpc_lb_l7_policy" "route_to_api" {
  vpc_id           = data.viettelidc_ovpc_vpc.main.id
  listener_id      = data.viettelidc_ovpc_lb_listener.http.id
  name             = "route-api"
  description      = "Direct /api/* calls to dedicated API pool"
  action           = "REDIRECT_TO_POOL"
  redirect_pool_id = data.viettelidc_ovpc_lb_pool.api.id
  priority         = 5
}
```

## Schema

### Required

- `action` (String) Policy action: `REJECT`, `REDIRECT_TO_URL`, or `REDIRECT_TO_POOL`. Changing this forces a new resource.
- `listener_id` (Number) The ID of the Listener (`vttLoadBalancerListenerId`) to which this L7 policy attaches. Must be an `HTTP` or `TERMINATED_HTTPS` listener. Changing this forces a new resource.
- `name` (String) Name of the L7 policy (1-255 characters, must match regex `^[a-zA-Z0-9.,@_\- ]+$`).
- `vpc_id` (Number) The ID of the VPC owning the Load Balancer. Changing this forces a new resource.

### Optional

- `description` (String) Description of the L7 policy (up to 255 characters).
- `priority` (Number) Evaluation priority (position) on the listener, starting from 1. Lower values are evaluated first.
- `redirect_pool_id` (Number) Target pool ID when `action` is `REDIRECT_TO_POOL`. Pool protocol must be `HTTP`, `PROXY`, or `PROXYV2`. Forbidden for other actions.
- `redirect_url` (String) Destination URL when `action` is `REDIRECT_TO_URL`. Must start with `http://` or `https://` (case-sensitive) and contain no spaces or control characters (max 1024 characters). Forbidden for other actions.

### Read-Only

- `id` (String) The internal CMP ID of the L7 policy (`vttLoadBalancerL7PolicyId`).
- `load_balancer_id` (Number) ID of the Load Balancer derived from the listener.
- `status` (String) Current status of the policy (`pending`, `success`, `active`, `error`).
