# viettelidc_ovpc_lb_l7_rule (Resource)

Manages a ViettelIDC vLB Layer 7 Rule attached to an L7 Policy.

Rules within the same Policy are combined using logical **AND**. All rules in a policy must match for the policy's action to be applied.

## Example Usage

### 1. URL Path Matching (STARTS_WITH, EQUAL_TO, REGEX)

```terraform
resource "viettelidc_ovpc_lb_l7_rule" "api_path" {
  vpc_id       = data.viettelidc_ovpc_vpc.main.id
  policy_id    = viettelidc_ovpc_lb_l7_policy.route_to_api.id
  type         = "PATH"
  compare_type = "STARTS_WITH"
  value        = "/api/" # Must start with '/'
}
```

### 2. Host Name Matching (FQDN)

```terraform
resource "viettelidc_ovpc_lb_l7_rule" "api_host" {
  vpc_id       = data.viettelidc_ovpc_vpc.main.id
  policy_id    = viettelidc_ovpc_lb_l7_policy.route_to_api.id
  type         = "HOST_NAME"
  compare_type = "EQUAL_TO"
  value        = "app.viettelidc.com.vn" # Do not include http:// or https://
}
```

### 3. HTTP Header Matching

```terraform
resource "viettelidc_ovpc_lb_l7_rule" "mobile_client" {
  vpc_id       = data.viettelidc_ovpc_vpc.main.id
  policy_id    = viettelidc_ovpc_lb_l7_policy.block_bad_bots.id
  type         = "HEADER"
  compare_type = "CONTAINS"
  key          = "User-Agent" # Required for HEADER type
  value        = "Scrapy"
}
```

### 4. Cookie Matching

```terraform
resource "viettelidc_ovpc_lb_l7_rule" "canary_cookie" {
  vpc_id       = data.viettelidc_ovpc_vpc.main.id

  type         = "COOKIE"
  compare_type = "EQUAL_TO"

```

### 5. File Extension Matching

```terraform

  vpc_id       = data.viettelidc_ovpc_vpc.main.id
```

## Schema

### Required

- `compare_type` (String) Comparison operation: `EQUAL_TO`, `STARTS_WITH`, `ENDS_WITH`, `CONTAINS`, or `REGEX`. With `FILE_TYPE`, only `EQUAL_TO` and `REGEX` are permitted.
- `policy_id` (Number) ID of the parent L7 Policy (`vttLoadBalancerL7PolicyId`). Changing this forces a new resource.
- `type` (String) Type of rule: `HOST_NAME`, `PATH`, `FILE_TYPE`, `HEADER`, or `COOKIE`.
- `value` (String) Value to match against (up to 255 characters, no whitespace or control characters).
  - For `PATH`: must begin with `/`.
  - For `FILE_TYPE`: must not begin with `.` (use `jpg`, not `.jpg`).
  - For `HOST_NAME`: must not contain `http://` or `https://`, and must not consist solely of digits.
- `vpc_id` (Number) The ID of the VPC owning the Load Balancer. Changing this forces a new resource.

### Optional

- `key` (String) Header or cookie name. Required when `type` is `HEADER` or `COOKIE`; forbidden for other rule types (max 255 characters, must be a valid RFC 7230 token, no semicolons, commas, equals, or quotes).

### Read-Only

- `id` (String) Internal CMP ID of the rule (`vttLoadBalancerL7RuleId`).
- `listener_id` (Number) Listener ID resolved automatically from the parent policy.
- `status` (String) Current lifecycle status of the rule (`pending`, `success`, `active`, `error`).

## Import

```shell
terraform import viettelidc_ovpc_lb_l7_rule.example 506857/41
```
