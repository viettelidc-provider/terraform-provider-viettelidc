# viettelidc_ovpc_autoscale_group (Resource)

ViettelIDC Autoscale Group. The API accepts two shapes: with is_autoscale the group scales on a metric and needs min_size, max_size and both thresholds; with has_load_balancer it is a fixed pool behind an existing load balancer and needs loadbalancer_id, loadbalancer_pool_id, subnet_id and port_number instead. All attributes are immutable (RequiresReplace / ForceNew). Read() uses list+filter because the API has no detail endpoint for ASG.

## Example Usage

```terraform
# The API accepts two shapes and they are not interchangeable.

# 1. Autoscale mode — the group grows and shrinks on a metric.
resource "viettelidc_ovpc_autoscale_group" "web" {
  name                = "web-asg"
  launch_template_id  = viettelidc_ovpc_launch_template.web.id
  is_autoscale        = true
  desired_capacity    = 2
  min_size            = 1
  max_size            = 5
  metric_type         = "CPU"
  scale_out_threshold = 80
  scale_in_threshold  = 20
  has_load_balancer   = false
  vpc_id              = data.viettelidc_ovpc_vpc.main.id
}

# 2. Load-balancer mode — a fixed pool registered behind an existing load
# balancer. min_size / max_size / the thresholds do not apply here and are not
# sent; supplying them is a config error.
resource "viettelidc_ovpc_autoscale_group" "fixed_pool" {
  name               = "web-pool"
  launch_template_id = viettelidc_ovpc_launch_template.web.id
  is_autoscale       = false
  desired_capacity   = 1

  has_load_balancer    = true
  loadbalancer_id      = viettelidc_ovpc_load_balancer.web.id
  loadbalancer_pool_id = viettelidc_ovpc_load_balancer.web.pools[0].id
  subnet_id            = viettelidc_ovpc_subnet.public.id
  port_number          = 80

  vpc_id = data.viettelidc_ovpc_vpc.main.id
}
```

## Required attributes per mode

Terraform cannot mark an attribute required only under a condition, so the
attributes below are declared optional and the rule is enforced when the plan is
built. Leaving one out is an error, not a default.

| Attribute | `is_autoscale = true` | `has_load_balancer = true` |
|---|---|---|
| `min_size` | **required** | do not set |
| `max_size` | **required** | do not set |
| `scale_out_threshold` | **required** | do not set |
| `scale_in_threshold` | **required** | do not set |
| `metric_type` | optional, defaults to `CPU` | do not set |
| `loadbalancer_id` | — | **required** |
| `loadbalancer_pool_id` | — | **required** |
| `subnet_id` | — | **required** |
| `port_number` | — | **required** |

`loadbalancer_id` and `loadbalancer_pool_id` come from the load balancer itself,
whether Terraform manages it or not:

```terraform
data "viettelidc_ovpc_load_balancer" "web" {
  name   = "web-lb"
  vpc_id = data.viettelidc_ovpc_vpc.main.id
}

# ... loadbalancer_id      = data.viettelidc_ovpc_load_balancer.web.id
# ... loadbalancer_pool_id = data.viettelidc_ovpc_load_balancer.web.pools[0].id
```

## Schema

### Required

- `desired_capacity` (Number) Desired number of instances. Immutable.
- `is_autoscale` (Boolean) Whether automatic scaling is enabled. Immutable.
- `launch_template_id` (String) ID of the Launch Template to use. Immutable.
- `name` (String) Autoscale Group name. Immutable.

### Optional

- `has_load_balancer` (Boolean) Whether the ASG is attached to a Load Balancer (default: false). Immutable.
- `loadbalancer_id` (String) Load balancer to register the group's instances with. Required when has_load_balancer is true. Immutable.
- `loadbalancer_pool_id` (String) Pool within loadbalancer_id to add members to. Required when has_load_balancer is true. Immutable.
- `max_size` (Number) Maximum number of instances. Required when is_autoscale is true; omit in load-balancer mode. Immutable.
- `metric_type` (String) Scaling metric type (default: "CPU"). Immutable.
- `min_size` (Number) Minimum number of instances. Required when is_autoscale is true; omit in load-balancer mode. Immutable.
- `port_number` (Number) Port the pool members listen on. Required when has_load_balancer is true. Immutable.
- `scale_in_threshold` (Number) CPU % threshold to scale in. Required when is_autoscale is true; omit in load-balancer mode. Immutable.
- `scale_out_threshold` (Number) CPU % threshold to scale out. Required when is_autoscale is true; omit in load-balancer mode. Immutable.
- `subnet_id` (String) Subnet the scaled instances are placed in. Required when has_load_balancer is true. Immutable.
- `vpc_id` (String) VPC ID. Falls back to the provider default vpc_id when unset.

### Read-Only

- `id` (String) Autoscale Group ID assigned by the system.
